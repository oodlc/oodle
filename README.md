# Oodle

People manage the spec: what the app is for, who uses it, what it holds, what they go through and what must never happen. Code is generated from it and checked against it. Merge the intent, not the code.

Nothing is built yet. Start with [VISION.md](VISION.md), and [0019](docs/decisions/0019-reset-the-spec-is-the-product.md) for why Oodle was reset.

The previous Oodle (v0, outcomes guarding code people write) is at tag [`v0.19.0`](https://github.com/oodlc/oodle/tree/v0.19.0).
